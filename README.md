# Course Project

A web application built with Python and Django for managing courses, user authentication, and enrollments.

## Features
* User Authentication (Signup & Login)
* Course Management (Add, Edit, List Courses)
* Responsive Web Interface

## Tech Stack
* **Language:** Python
* **Framework:** Django
* **Database:** SQLite
